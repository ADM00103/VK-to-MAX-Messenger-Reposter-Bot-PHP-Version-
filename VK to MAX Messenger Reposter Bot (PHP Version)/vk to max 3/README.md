# 🤖 VK to MAX Messenger Reposter Bot (PHP)

Простой и надежный PHP-бот для автоматического репоста контента из группы ВКонтакте в канал мессенджера MAX (VK Teams).

## 🚀 Возможности

- **Умная очередь**: Проверяет последние 10 постов и репостит все пропущенные в хронологическом порядке
- **Поддержка медиа**: Скачивает и перезагружает фото, видео и документы
- **Интерактивные кнопки**: Добавляет кнопку "🔗 Открыть в VK" к каждому сообщению
- **Веб-интерфейс**: Удобная панель управления через браузер
- **Безопасность**: Система белых списков (реагирует только на авторизованных администраторов)
- **Заполнение канала**: Команда `/fill 10` для мгновенной загрузки последних 10 постов
- **Логирование**: Полное логирование всех действий с ротацией файлов

## 🛠️ Установка

### 1. Требования
- PHP 7.4 или выше
- Расширение cURL
- Доступ к API VK и MAX

### 2. Клонирование репозитория
```bash
git clone https://github.com/YOUR_USERNAME/vk-to-max-php.git
cd vk-to-max-php

###  3. Настройка
Отредактируйте файл config.php:

php
define('VK_SERVICE_TOKEN', 'ваш_сервисный_токен');
define('VK_GROUP_ID', -123456789); // ID группы с минусом
define('MAX_BOT_TOKEN', 'токен_бота_max');
define('MAX_CHAT_ID', '-123456789'); // ID канала
define('ADMIN_IDS', [123456789]); // Ваш ID в MAX

4. Настройка прав
bash
chmod 755 logs/
chmod 644 config.php

5. Запуск
bash
# Ручной запуск
php bot.php

# Запуск с проверкой
php bot.php /check

# Заполнение канала 10 постами
php bot.php /fill 10


6. Настройка cron (автоматическая проверка)
Добавьте в crontab:

bash
*/5 * * * * /usr/bin/php /path/to/vk-to-max-php/bot.php >> /path/to/vk-to-max-php/logs/cron.log 2>&1
🎮 Команды бота
Отправляйте команды в личные сообщения боту:

Команда	Описание
/status	Показать статус бота
/check	Немедленно проверить новые посты
/fill N	Заполнить канал последними N постами (макс 50)
/log	Показать последние 15 записей лога
/stop	Остановить бота

🐛 Устранение неполадок
Проблема: Бот не отвечает на команды
Решение: Проверьте, что ваш ID добавлен в ADMIN_IDS

Проблема: Ошибка "Unauthorized access attempt"
Решение:

Найдите в логах ваш ID: ⛔ Unauthorized access attempt (ID: 12345678)

Добавьте этот ID в ADMIN_IDS в config.php

Проблема: Не загружаются фотографии
Решение:

Проверьте права на запись в временную папку

Убедитесь, что установлено расширение GD или Imagick

Проблема: Ошибка "ProxyError"
Решение: В коде уже отключена проверка SSL, если ошибка остается - проверьте настройки прокси в системе
