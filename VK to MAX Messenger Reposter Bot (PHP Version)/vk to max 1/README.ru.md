# 🤖 VK to MAX PHP Reposter Bot

Простой и надёжный PHP‑бот для автоматического репоста контента из группы ВКонтакте в канал мессенджера MAX (на базе VK Teams).

## Возможности 🚀

- **Умная очередь**: проверяет последние 10 постов и репостит **все пропущенные** в хронологическом порядке (если бот был какое‑то время выключен).  
- **Медиа‑поддержка**: переносит текст, фото (берёт самое качественное), а видео оформляет кликабельной ссылкой на VK.  
- **Кнопка "Открыть в VK"**: к каждому сообщению добавляется удобная ссылка на оригинальный пост.  
- **Мини‑админ‑панель**: управляется через личные сообщения в MAX командами `/status`, `/check`, `/fill N`, `/log`, `/stop`.  
- **Безопасность**: бот реагирует только на команды от ID, указанных в `ADMIN_IDS`.  
- **Работа через CLI**: можно запускать как постоянный процесс (демон) на сервере или через планировщик (cron).

## Установка 🛠️

### 1. Установить PHP

1. Скачайте PHP с официального сайта: https://www.php.net/downloads  
2. При установке отметьте галочку **"Add to PATH"** (или настройте путь к `php.exe` вручную).  
3. Проверьте, что работает команда:

```bash
php -v
```

На экране должна появиться информация о версии PHP.

---

### 2. Скачать бота

```bash
git clone https://github.com/YOUR_USERNAME/vk-max-php-reposter.git
cd vk-max-php-reposter
```

Создайте папку для данных:

```bash
mkdir data
```

---

### 3. Собрать секретные ключи 🔑

Нужно подготовить 5 параметров:

1. **VK_SERVICE_TOKEN** — сервисный ключ доступа ВКонтакте  
   - Зайдите: https://dev.vk.com/apps  
   - Нажмите «Создать приложение».  
   - Тип — «Сайт» или `Standalone`, имя любое.  
   - В настройках приложения найдите поле **«Сервисный ключ доступа»** — скопируйте.

2. **VK_GROUP_ID** — ID группы ВКонтакте  
   - Откройте любой пост вашей группы.  
   - В адресной строке будет что‑то вроде `vk.com/wall-174162942_123`.  
   - Часть с минусом `-174162942` — это ID группы. Важно скопировать минус!

3. **MAX_BOT_TOKEN** — токен бота в MAX  
   - В мессенджере MAX найдите системного бота (например, `@MasterBot` / `@Metabot`).  
   - Отправьте команду `/newbot`.  
   - Придумайте имя и логин, получите токен — **сохраните его**.

4. **MAX_CHAT_ID** — ID канала, куда постить  
   - Создайте канал в MAX.  
   - Добавьте туда вашего бота как администратора.  
   - Узнать `chat_id` можно у администраторов или из лога/ответа API (проще всего один раз отправить любое сообщение и посмотреть лог).

5. **ADMIN_IDS** — список админов  
   - При первом запуске бот покажет в логе строку `⛔ Unauthorized access attempt (ID: 12345678)` если ему кто‑то напишет.  
   - Это число `12345678` и есть ваш ID.  
   - Впишите его в `ADMIN_IDS` в `config.php`.

---

### 4. Настройка `config.php` ⚙️

Откройте файл `config.php` в любом редакторе и замените значения:

```php
define('VK_SERVICE_TOKEN', 'ВАШ_СЕРВИСНЫЙ_КЛЮЧ_ВК');
define('VK_GROUP_ID', -174162942);

define('MAX_BOT_TOKEN', 'ВАШ_ТОКЕН_БОТА_MAX');
define('MAX_CHAT_ID', -69410493377140);

define('ADMIN_IDS', '12345678');
```

Сохраните файл.

---

### 5. Запуск бота 🚀

#### Вариант А: Запуск как постоянный процесс

1. Откройте терминал в папке бота.  
2. Выполните:

```bash
php vk_max_reposter.php
```

Если увидите строку:

```text
=== 🤖 VK TO MAX REPOSTER (PHP) STARTED ===
```

— бот запущен и каждые 30 секунд проверяет вашу группу ВК.

> При закрытии окна терминала бот останавливается.  
> Чтобы он работал всегда, нужно запускать его на сервере (VDS) через `screen`, `tmux` или systemd‑сервис.

#### Вариант Б: Запуск по cron (периодическая проверка)

Можно настроить cron‑задачу, например, проверять новые посты каждые 5 минут, вызовом отдельного скрипта, который запускает только `check_new_posts()`. (Тут нужно будет вынести функцию проверки в отдельный файл/режим.)

## Управление ботом (команды) 🎮

Напишите вашему боту **в личные сообщения** в MAX (с того ID, который указан в `ADMIN_IDS`):

- `/status` — показать, жив ли бот.  
- `/check` — немедленно проверить ВК на новые посты и отправить их.  
- `/fill 10` — взять последние 10 постов и залить их в канал (удобно для нового канала).  
- `/log` — показать последние 15 строк лога.  
- `/stop` — остановить работу скрипта (процесс завершится).

## Частые вопросы ❓

**Q: Бот выключился, когда я закрыл консоль.**  
A: Да, это нормально. Скрипт работает, пока открыт терминал. Для круглосуточной работы запускайте его на сервере (VDS) и закрепляйте через `screen`, `tmux` или systemd.

**Q: Пишет "Unauthorized access attempt" и не отвечает на мои команды.**  
A: Вы ещё не указали свой ID в `ADMIN_IDS`. Посмотрите число в логе после такой надписи и впишите его в `config.php`.

**Q: Ошибки cURL / ProxyError.**  
A: В коде отключён системный прокси (`curl_setopt($ch, CURLOPT_PROXY, '');`). Если используете VPN/прокси на сервере — попробуйте отключить или явно прописать нужные настройки.

**Q: Почему видео не грузится прямо в MAX, а только ссылкой?**  
A: Для упрощения скрипт отправляет ссылку на видео ВКонтакте. Можно доработать: сначала получать ссылку `player` у VK API, а затем использовать API MAX для загрузки/вставки видео.
